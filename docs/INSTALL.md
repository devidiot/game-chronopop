# 설치해서 즐기고 지우기

앱스토어/플레이스토어를 거치지 않고 폰에 올리는 방법이다.

> **iOS에는 APK를 설치할 수 없다.** APK는 안드로이드 형식이다.
> 아이폰은 아래의 **PWA(홈 화면에 추가)** 방식을 쓴다. 서명도, 7일 만료도,
> 개발자 계정도 필요 없고 아이콘을 길게 눌러 지우면 흔적 없이 사라진다.

---

## iPhone — 홈 화면에 추가 (PWA)

### 방법 A. GitHub Pages (설정 완료 · 완전 오프라인)

**이미 배포되어 있다.** 주소는

```
https://devidiot.github.io/game-chronopop/
```

고칠 게 있으면 명령어 한 줄이면 다시 올라간다.

```bash
cd chronopop
npm run deploy         # 빌드 → gh-pages 브랜치 푸시 → Pages 반영
```

`npm run deploy` 는 `scripts/deploy-pages.mjs` 를 돌린다. 소스는 `main` 에,
배포본은 `gh-pages` 에 둬서 `main` 의 커밋 이력이 빌드 산출물로 더러워지지 않는다.
반영까지 30초~1분 걸린다.

> 다른 호스팅을 쓰고 싶다면 `npm run build` 후 `dist` 폴더를
> [Netlify Drop](https://app.netlify.com/drop) 에 끌어다 놓아도 된다.
> Cloudflare Pages, Vercel 등 HTTPS 정적 호스팅이면 아무거나 동작한다.

위 주소를 아이폰 **Safari**로 연다. (크롬 아님 — 홈 화면 추가는 Safari만 된다)

1. 하단 **공유 버튼** 탭
2. **홈 화면에 추가**
3. 홈 화면에 생긴 ChronoPop 아이콘으로 실행
4. **이때 한 번은 인터넷이 연결된 상태여야 한다** ← 아래 설명

이후 비행기 모드로 바꿔도 아이콘을 누르면 그대로 실행된다.

#### 왜 아이콘으로 한 번 열어야 하나

iOS의 홈 화면 웹 앱은 **Safari와 저장 공간을 공유하지 않는다.** Safari에서 아무리
많이 플레이했어도 홈 화면 앱은 자기 캐시를 처음부터 새로 채운다. 그래서 아이콘을
만든 뒤 온라인 상태로 한 번 실행해줘야 한다.

그 한 번에 게임 전체(HTML·JS·CSS·아이콘, 합쳐서 약 420KB)를 통째로 내려받는다.
빌드할 때 `scripts/precache-sw.mjs` 가 서비스 워커에 실제 파일 목록을 박아넣기
때문에, **화면을 열자마자 준비가 끝난다.** 게임을 한 판 할 필요도 없다.

#### 오프라인인지 확인하는 법

아이폰을 **비행기 모드**로 바꾸고 홈 화면 아이콘을 누른다. 게임이 정상적으로
뜨면 성공이다. (Safari 탭이 아니라 반드시 홈 화면 아이콘으로 확인할 것)

### 방법 B. Mac을 서버로 (설치 없이 바로 해보기)

아이폰과 Mac이 **같은 Wi-Fi**에 있어야 한다.

```bash
cd chronopop
npm install
npm run dev            # 또는 npm run build && npm run preview
```

Mac의 IP를 확인하고

```bash
ipconfig getifaddr en0     # 예: 192.168.0.12
```

아이폰 Safari에서 `http://192.168.0.12:5173` 접속.
홈 화면에 추가하면 아이콘도 생긴다.

- 장점: 올릴 곳이 필요 없다
- 단점: **http라서 오프라인 캐시가 안 된다.** Mac에서 서버를 끄면 실행되지 않는다

### 방법 C. 파일 하나로 주고받기 (아이폰에는 권장하지 않음)

```bash
npm run build:single   # dist/chronopop-single.html (약 35KB)
```

이 파일 하나에 게임 전체가 들어 있고 서버 없이 브라우저로 바로 열린다.

- **Mac·PC·안드로이드**: 파일을 브라우저로 열면 그대로 플레이된다
- **아이폰**: iOS는 파일 앱에서 HTML을 탭해도 미리보기(Quick Look)로만 열려
  자바스크립트가 제대로 돌지 않는 경우가 많고, Safari 주소창에 `file://` 을
  직접 입력할 수도 없다. **아이폰에서는 방법 A나 B를 쓰는 편이 확실하다.**

홈 화면 아이콘도 생기지 않는다(웹 앱 매니페스트가 로드되지 않으므로).

### 지우기

홈 화면 아이콘을 길게 눌러 **앱 제거**. 기록까지 지우려면
설정 → Safari → 고급 → 웹사이트 데이터에서 해당 항목을 삭제한다.

## Android — APK 설치

```bash
cd chronopop
npm install
npm run android:apk    # build/chronopop.apk 생성
```

필요한 것: JDK 21 이상, Android SDK (없다면 [BUILD.md](./BUILD.md) 참고)

### 폰에 넣기

**USB 케이블**

```bash
adb install -r build/chronopop.apk
```

**케이블 없이**: APK 파일을 구글 드라이브·카카오톡 나에게 보내기 등으로 옮긴 뒤
폰에서 탭한다. "이 출처의 앱 설치 허용"을 한 번 켜주면 설치된다.

디버그 서명이라 스토어 앱과 달리 설치 시 경고가 뜬다. 정상이다.

### 지우기

앱 아이콘 길게 누르기 → 제거. 일반 앱과 똑같다.

## 소리가 안 날 때

효과음은 오디오 파일 없이 WebAudio로 합성한다. 안 들린다면 순서대로 확인한다.

1. **볼륨** — 이 게임은 오디오 세션을 `transient` 로 선언한다. 짧은 알림음용
   분류라서 **무음 스위치와 상관없이 소리가 나고**, 음악을 틀어둔 채 플레이해도
   음악이 끊기지 않고 잠깐 작아졌다 돌아온다.
2. **화면을 한 번 터치했는지** — 브라우저는 사용자가 조작하기 전에는 소리를
   내주지 않는다. 시작 버튼을 누르거나 보드를 만지면 풀린다.
3. **타이틀 화면의 소리 버튼** — `🔇 소리 끔` 이면 꺼진 상태다. 누르면 켜지면서
   확인용으로 한 번 소리가 난다.

## 어떤 걸 고를까

| 상황                                    | 추천                       |
| --------------------------------------- | -------------------------- |
| 아이폰에서 제대로 즐기고 싶다           | iOS 방법 A (GitHub Pages)  |
| 지금 당장 30초 안에 해보고 싶다         | iOS 방법 B (Mac 서버)      |
| PC·안드로이드에 파일로 보내주고 싶다    | 방법 C (단일 HTML)         |
| 안드로이드 폰에 앱으로 설치하고 싶다    | APK                        |

## 왜 서버가 필요한가

게임 자체는 서버 없이도 돌아간다(방법 C). 서버가 필요한 것은 **PWA 기능** 때문이다.
홈 화면 추가와 오프라인 캐시(서비스 워커)는 브라우저가 보안 컨텍스트
(HTTPS 또는 localhost)에서만 허용하며, `file://` 에서는 동작하지 않는다.

다만 방법 A는 **한 번만 올리면 그 뒤로는 서버가 필요 없다.** 서비스 워커가
게임을 폰에 통째로 캐시하므로 Mac을 꺼도, 비행기 모드에서도 실행된다.
